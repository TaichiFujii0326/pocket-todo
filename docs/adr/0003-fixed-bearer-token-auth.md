# 認証は固定Bearerトークン1本。脅威モデルは「課金悪用」

利用者は本人だけなので、ログイン画面や短期セッションは作らず、自分で決めた合言葉をヘッダーで検証するだけにした。守るべき最大の実害は「トークン漏洩時にClaude APIのクレジットを溶かされること」と定義し(2026-09-19のgrillingセッションで合意)、それに対して3層で防御する: ①Anthropicをプリペイド+自動チャージOFFにして被害上限を残高に固定 ②認証通過後のリクエストを毎分5件に制限して消費速度を落とす ③漏洩に気づいたら `wrangler secret put AUTH_TOKEN` で即ローテーション。

## Consequences

- 受容したリスク: トークンは有効期限なし・端末別失効なし・localStorage保存。外部セキュリティレビュー(docs/reviews/2026-09-19-codex-v1.md のM-04)でも指摘されたが、48文字hexの総当たりは非現実的であり、上記3層で被害上限が確定しているため意図的に受容した
- 一般公開(他ユーザーを持つ)段階になったら、この決定は破棄してOAuth等に移行する
