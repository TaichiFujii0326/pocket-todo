# 202即返し+バックグラウンド処理。「タスクを絶対失わない」を最優先する

APIは受理した瞬間に202を返し、AI(意図判定・分類)とNotion書き込みはwaitUntilで応答後に行う。「2秒で放り込む」体感はAIの応答時間(1〜2秒+)と両立しないため、待たせない設計を選んだ。引き換えに結果を即座に返せないので、安全側の原則を2つ置いた: (1) 解釈に失敗した入力はタイトルだけのタスクとして必ず登録する(フォールバック登録)、(2) 既存タスクへの操作(完了/削除等)は対象を特定できなければ実行せず、その旨をWeb Pushで通知する(誤爆より空振り)。

## Consequences

- AI呼び出しにはSDK既定より短いタイムアウトを明示する必要がある。waitUntilの実行猶予(約30秒)を超えるとフォールバックごと失われるため(外部レビューM-06で顕在化)
- 処理結果のフィードバックは通知チャネル(Web Push)が担う。通知未設定のユーザーは操作結果をNotionを見て確認するしかない
